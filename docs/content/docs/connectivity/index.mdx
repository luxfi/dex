# Connectivity Overview

> **Contact**: connectivity@lux.network | +1-833-LUX-TRADE | [Enterprise Portal](https://enterprise.lux.network)

## Introduction

LX DEX provides multiple connectivity options designed for different trading requirements, from retail traders accessing via public internet to institutional market makers requiring sub-microsecond latency through colocation. This documentation covers all available connectivity methods, regional endpoints, latency specifications, and enterprise connectivity programs.

## Connectivity Decision Matrix

### Choose Public API if:
- Trading volume < 10,000 orders/day
- Latency requirements > 50ms acceptable
- No dedicated infrastructure budget
- Getting started or testing

### Choose VPN if:
- Trading volume 10,000-100,000 orders/day
- Latency requirements 5-50ms
- Need encrypted access from multiple locations
- Regulatory requirement for secure channels

### Choose Dedicated if:
- Trading volume 100,000-1,000,000 orders/day
- Latency requirements < 1ms
- Running algorithmic strategies
- Need guaranteed bandwidth

### Choose Colocation if:
- Trading volume > 1,000,000 orders/day
- Latency requirements < 100us
- High-frequency trading strategies
- Market making operations

## Getting Started

### 1. Public API Access

Instant access via public endpoints:

```bash
# Production
curl https://api.lux.network/v1/health

# WebSocket
wscat -c wss://ws.lux.network/v1
```

### 2. VPN Access Request

Contact our connectivity team:

```
Email: connectivity@lux.network
Subject: VPN Access Request - [Company Name]

Required Information:
- Company name and registration
- Expected trading volume
- Primary users (names, emails)
- Preferred VPN protocol
- Source IP ranges
```

### 3. Dedicated Connection

Submit enterprise connectivity request:

```
https://enterprise.lux.network/connectivity/dedicated
```

### 4. Colocation Program

Apply for colocation program:

```
https://enterprise.lux.network/connectivity/colocation
```
