# Institutional Services

LX provides institutional-grade infrastructure purpose-built for sophisticated market participants requiring the highest standards of performance, security, and compliance.

## Overview

LX Institutional combines the transparency and self-custody benefits of decentralized finance with the performance, reliability, and compliance capabilities expected by regulated financial institutions.

| Capability | Traditional Exchange | LX Institutional |
|------------|---------------------|---------------------|
| Settlement | T+2 (equities), T+1 (futures) | **T+0 Atomic** |
| Custody | Counterparty risk | **Self-custody + MPC** |
| Latency | 10-100 microseconds | **487 nanoseconds** |
| Throughput | 100K-1M orders/sec | **434M orders/sec** |
| Transparency | Opaque order routing | **Full on-chain audit** |
| Market Hours | Limited | **24/7/365** |
