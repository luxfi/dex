# Consensus Layer

LX DEX uses a custom DAG-based consensus protocol designed for ultra-low latency trading.

## Overview

The consensus layer provides:
- **1ms block finality** for instant trade settlement
- **DAG structure** for parallel block processing
- **K=3 validator threshold** for Byzantine fault tolerance
- **Quantum-resistant signatures** for future-proof security

## Consensus Protocol

### FPC (Fast Probabilistic Consensus)

The protocol uses optimistic confirmation with fallback to Byzantine agreement:

```go
type ConsensusEngine struct {
    K           int           // Validator threshold (default: 3)
    Alpha       float64       // Confidence threshold (default: 0.8)
    BlockTime   time.Duration // Target block time (default: 1ms)
    Validators  []Validator   // Active validator set
}

func (c *ConsensusEngine) ProposeBlock(block *Block) error {
    // 1. Broadcast to validators
    // 2. Collect K signatures
    // 3. Finalize when alpha threshold met
}
```

### Finality

Blocks achieve finality when:
1. K validators have signed
2. Cumulative weight exceeds threshold
3. No conflicting blocks exist

```go
func (c *ConsensusEngine) CheckFinality(block *Block) bool {
    signatures := c.GetBlockSignatures(block.Hash)
    
    // Need K signatures
    if len(signatures) < c.K {
        return false
    }
    
    // Check cumulative stake weight
    weight := c.CalculateWeight(signatures)
    return weight >= c.Alpha
}
```

## Block Production

### Proposer Selection

Deterministic selection based on stake-weighted random:

```go
func (c *ConsensusEngine) SelectProposer(height uint64) ValidatorID {
    seed := hash(height, c.GetEpochSeed())
    
    totalStake := c.TotalStake()
    point := seed % totalStake
    
    cumulative := uint64(0)
    for _, v := range c.Validators {
        cumulative += v.Stake
        if cumulative > point {
            return v.ID
        }
    }
}
```

## Transaction Ordering

### Deterministic Ordering

Transactions within a block are ordered by:
1. Priority fee (highest first)
2. Nonce (for same sender)
3. Hash (tiebreaker)

```go
func OrderTransactions(txs []Transaction) []Transaction {
    sort.Slice(txs, func(i, j int) bool {
        // Priority fee
        if txs[i].PriorityFee != txs[j].PriorityFee {
            return txs[i].PriorityFee > txs[j].PriorityFee
        }
        // Same sender: by nonce
        if txs[i].From == txs[j].From {
            return txs[i].Nonce < txs[j].Nonce
        }
        // Tiebreaker: hash
        return txs[i].Hash < txs[j].Hash
    })
    return txs
}
```

## Cryptography

### BLS Signatures

Aggregate signatures for efficient verification:

```go
// Sign block
```

## State Machine

### State Transitions

```go
type StateMachine struct {
    State     State
    Height    uint64
    StateRoot Hash
}

func (sm *StateMachine) Apply(block *Block) error {
    for _, tx := range block.Txs {
        if err := sm.ExecuteTx(tx); err != nil {
            return err
        }
    }
    
    sm.Height = block.Header.Height
    sm.StateRoot = sm.ComputeStateRoot()
    return nil
}
```
