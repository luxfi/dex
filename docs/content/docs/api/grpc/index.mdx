# gRPC API Overview

The LX gRPC API provides high-performance, strongly-typed communication for internal node operations. Built on Protocol Buffers 3, it offers sub-millisecond latency for order execution and real-time market data streaming.

## Why gRPC

| Feature | gRPC | REST | WebSocket |
|---------|------|------|-----------|
| Latency | ~50us | ~1ms | ~500us |
| Type Safety | Strong (protobuf) | Weak (JSON) | None |
| Streaming | Bidirectional | None | Server-push |
| Code Generation | Native | Manual | Manual |
| Binary Protocol | Yes | No | Optional |

## Service Definition

The LX exposes a single unified service with multiple RPC methods:

```protobuf
syntax = "proto3";

package lxdex;

option go_package = "github.com/luxfi/dex/pkg/grpc/pb";

// LX gRPC Service for internal Lux Network IPC
service LXDEXService {
  // Order Management
  rpc PlaceOrder(PlaceOrderRequest) returns (PlaceOrderResponse);
  rpc CancelOrder(CancelOrderRequest) returns (CancelOrderResponse);
  rpc GetOrder(GetOrderRequest) returns (Order);
  rpc GetOrders(GetOrdersRequest) returns (GetOrdersResponse);

  // Market Data
  rpc GetOrderBook(GetOrderBookRequest) returns (OrderBook);
  rpc StreamOrderBook(StreamOrderBookRequest) returns (stream OrderBookUpdate);
  rpc GetTrades(GetTradesRequest) returns (GetTradesResponse);
  rpc StreamTrades(StreamTradesRequest) returns (stream Trade);

  // Account Management
  rpc GetBalance(GetBalanceRequest) returns (Balance);
  rpc GetPositions(GetPositionsRequest) returns (GetPositionsResponse);

  // Node Management
  rpc GetNodeInfo(GetNodeInfoRequest) returns (NodeInfo);
  rpc GetPeers(GetPeersRequest) returns (GetPeersResponse);
  rpc Ping(PingRequest) returns (PingResponse);
}
```

## Common Enums

### OrderType

```protobuf
enum OrderType {
  LIMIT = 0;       // Standard limit order
  MARKET = 1;      // Execute at best available price
  STOP = 2;        // Market order triggered at stop price
  STOP_LIMIT = 3;  // Limit order triggered at stop price
  ICEBERG = 4;     // Large order split into visible chunks
  PEG = 5;         // Order pegged to reference price
```

### OrderStatus

```protobuf
enum OrderStatus {
  OPEN = 0;       // Order is active in book
  PARTIAL = 1;    // Partially filled
  FILLED = 2;     // Completely filled
```

## Error Handling

gRPC uses standard status codes. LX maps domain errors to appropriate codes:

| gRPC Code | HTTP | Description | Example |
|-----------|------|-------------|---------|
| `OK` | 200 | Success | Order placed |
| `INVALID_ARGUMENT` | 400 | Bad request | Invalid price |
| `NOT_FOUND` | 404 | Resource missing | Order not found |
| `ALREADY_EXISTS` | 409 | Duplicate | Client order ID exists |
| `PERMISSION_DENIED` | 403 | Unauthorized | Invalid API key |
| `RESOURCE_EXHAUSTED` | 429 | Rate limited | Too many requests |
| `FAILED_PRECONDITION` | 400 | State conflict | Insufficient balance |
| `ABORTED` | 409 | Concurrency | Order already cancelled |
| `UNAVAILABLE` | 503 | Service down | Matching engine offline |
| `INTERNAL` | 500 | Server error | Unexpected failure |

### Error Details

```protobuf
// Standard error response structure
message ErrorDetail {
  string code = 1;           // Machine-readable error code
  string message = 2;        // Human-readable message
  map<string, string> metadata = 3;  // Additional context
}
```

```go
// Go error handling example
resp, err := client.PlaceOrder(ctx, req)
if err != nil {
    st, ok := status.FromError(err)
    if !ok {
        return fmt.Errorf("unknown error: %w", err)
    }

    switch st.Code() {
    case codes.InvalidArgument:
        return fmt.Errorf("invalid order: %s", st.Message())
    case codes.ResourceExhausted:
        return fmt.Errorf("rate limited, retry after backoff")
    case codes.FailedPrecondition:
        return fmt.Errorf("insufficient balance")
    default:
        return fmt.Errorf("grpc error %s: %s", st.Code(), st.Message())
    }
}
```

## Connection Management

### Keep-Alive Settings

```go
// Recommended client configuration
conn, err := grpc.Dial(
    "dex.lux.network:50051",
    grpc.WithKeepaliveParams(keepalive.ClientParameters{
        Time:                10 * time.Second,  // Ping interval
        Timeout:             3 * time.Second,   // Ping timeout
        PermitWithoutStream: true,              // Ping even without active streams
    }),
    grpc.WithDefaultCallOptions(
        grpc.MaxCallRecvMsgSize(4*1024*1024),  // 4MB receive
        grpc.MaxCallSendMsgSize(4*1024*1024),  // 4MB send
    ),
)
```

### Connection Pooling

For high-throughput applications, use connection pooling:

```go
type ConnectionPool struct {
    conns []*grpc.ClientConn
    idx   uint64
}

func (p *ConnectionPool) Get() *grpc.ClientConn {
    n := atomic.AddUint64(&p.idx, 1)
    return p.conns[n%uint64(len(p.conns))]
}
```

## Quick Start

### Go Client

```go
package main

import (
    "context"
    "log"

    pb "github.com/luxfi/dex/pkg/grpc/gen"
    "google.golang.org/grpc"
    "google.golang.org/grpc/credentials/insecure"
)

func main() {
    conn, err := grpc.Dial(
        "localhost:50051",
        grpc.WithTransportCredentials(insecure.NewCredentials()),
    )
    if err != nil {
        log.Fatal(err)
    }
    defer conn.Close()

    client := pb.NewLXDEXServiceClient(conn)

    // Place an order
    resp, err := client.PlaceOrder(context.Background(), &pb.PlaceOrderRequest{
        Symbol:      "LUX-USDC",
        Type:        pb.OrderType_LIMIT,
        Side:        pb.OrderSide_BUY,
        Price:       100.50,
        Size:        10.0,
        UserId:      "user123",
        TimeInForce: pb.TimeInForce_GTC,
    })
    if err != nil {
        log.Fatal(err)
    }

    log.Printf("Order placed: ID=%d Status=%s", resp.OrderId, resp.Status)
}
```
